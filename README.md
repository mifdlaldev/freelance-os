# Freelance OS

> Sistem operasi untuk perjalanan freelance-mu. Panduan lengkap menjadi freelancer sukses di platform global.

## 📋 Overview

**Freelance OS** adalah dokumentasi strategis terstruktur yang mencakup seluruh aspek perjalanan freelance — dari riset pasar, roadmap bulanan, strategi platform, penentuan niche, portofolio, proposal, pricing, client acquisition, hingga review berkala.

Semua dalam satu tempat, dirancang untuk dieksekusi.

## 🚀 Cara Menggunakan

1. **Mulai** — Baca `Freelance-Roadmap/docs/index.md`
2. **Roadmap** — Ikuti bulan berjalan di `docs/02-roadmap/`
3. **Review** — Evaluasi progres mingguan & bulanan
4. **Iterasi** — Update portofolio, proposal, dan pricing secara berkala

## 🧰 Tools

Dokumentasi ini menggunakan [MkDocs](https://www.mkdocs.org/) dengan tema Material untuk navigasi yang rapi.

```bash
# Install
pip install mkdocs mkdocs-material

# Preview lokal
mkdocs serve

# Build
mkdocs build
```

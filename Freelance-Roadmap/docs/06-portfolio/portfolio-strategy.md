# Portfolio Strategy

## Prinsip
- **Quality over quantity** — 5 project bagus > 20 project biasa
- **Show results** — Pakai metrik konkret
- **Targeted** — Portfolio disesuaikan dengan niche
- **Up-to-date** — Update setiap bulan

## Struktur Portfolio
1. **Project title** — Jelas, deskriptif
2. **Tech stack** — Tools yang digunakan
3. **Problem** — Masalah yang dipecahkan
4. **Solution** — Pendekatan yang diambil
5. **Results** — Dampak dengan angka
6. **Links** — Demo / GitHub / screenshot

## Platform Portfolio
- **Website pribadi** — Wajib, sebagai central hub
- **GitHub** — Untuk code-heavy projects
- **Platform profile** — Upwork, Fiverr, Contra
- **LinkedIn** — Featured section
- **Behance / Dribbble** — Untuk design work

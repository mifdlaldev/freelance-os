# Portfolio Website

## Platform Options
| Platform | Kelebihan | Kekurangan |
|----------|----------|------------|
| Next.js + Vercel | Gratis, performa tinggi | Perlu maintenance |
| Astro + Netlify | Ringan, cepat | Learning curve |
| WordPress | Mudah, banyak template | Berat, kena biaya |
| Carrd | Super sederhana, $19/tahun | Terbatas |
| Super.so | Notion-based, cepat | Bayar untuk domain |

## Halaman Wajib
1. **Home** — Hero, value proposition
2. **Portfolio** — Project showcase
3. **Services** — What you offer
4. **About** — Story, experience
5. **Contact** — Form / CTA

## Tips
- Domain: [nama].com atau [nama].dev
- Load time <3 detik
- Mobile responsive
- Sertakan testimonial
- CTA jelas di tiap halaman

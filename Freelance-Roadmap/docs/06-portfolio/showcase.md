# Showcase

Cara menampilkan proyek secara efektif di berbagai platform.

## Format Showcase

### Screenshot
- Gunakan mockup (bukan screenshot mentah)
- Tools: CleanShot, Snagit, Mockup.systems
- Ukuran konsisten

### Case Study Format
```
Problem → Approach → Solution → Results
```

### Video Demo
- Screen recording dengan voiceover
- Tools: Loom, OBS, ScreenStudio
- Durasi: 2–5 menit

### Live Demo
- Deploy di Vercel / Netlify
- Sertakan test credentials jika perlu

## Checklist Tiap Showcase
- [ ] Judul jelas
- [ ] Masalah yang dipecahkan
- [ ] Tech stack
- [ ] Screenshot / GIF
- [ ] Hasil konkret
- [ ] Link (jika publik)
- [ ] Testimonial (jika ada)

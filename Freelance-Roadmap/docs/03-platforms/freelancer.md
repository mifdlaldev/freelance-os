# Freelancer.com

## Overview
Platform freelance berbasis bidding dan contest. Cocok untuk berbagai kategori.

## Setup Profil
- [ ] Headline profesional dengan keyword
- [ ] Portfolio dengan contoh kerja
- [ ] Verifikasi ID untuk meningkatkan kredibilitas
- [ ] Ikut skill test untuk badge

## Strategi
- **Contest**: Ikuti contest untuk membangun portfolio awal
- **Bidding**: Kirim proposal yang personalized
- **Membership**: Membership berbayar memberi lebih banyak bid

## Tips
- Persaingan harga cukup ketat
- Fokus ke negara dengan budget lebih tinggi (US, UK, AU)
- Response cepat sangat penting

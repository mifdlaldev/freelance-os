# Toptal

## Overview
Platform freelance exclusive — hanya menerima <3% aplikasi. Target: klien enterprise dengan budget besar.

## Proses Seleksi
1. **Aplikasi awal** — Screening skill & English
2. **Technical interview** — Live coding / problem solving
3. **Test project** — Proyek real-world
4. **Final interview** — Komunikasi & profesionalisme

## Strategi
- **Persiapan matang** untuk technical interview
- **Portfolio** harus menunjukkan expert-level work
- **Rate** bisa $60–$200+/jam setelah accepted

## Tips
- Proses seleksi bisa makan waktu 2–4 minggu
- Standar sangat tinggi, tapi reward sebanding
- Klien biasanya sudah siap budget besar

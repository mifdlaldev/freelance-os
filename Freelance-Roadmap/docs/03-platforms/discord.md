# Discord

## Overview
Discord server komunitas tech makin populer untuk freelance opportunities — terutama untuk developer dan AI/ML work.

## Server yang Relevan
- **AI/ML Discord** — Server open source project AI
- **Web Dev Discord** — Komunitas framework tertentu
- **Freelance Discord** — Server khusus freelance

## Strategi
- **Join server sesuai tech stack**
- **Cek channel #jobs, #freelance, #hiring**
- **Bangun presence** — bantu jawab pertanyaan teknis
- **Apply via DM** saat ada posting lowongan

## Tips
- Klien di Discord biasanya lebih tech-savvy
- Komunikasi informal, tapi tetap profesional
- Rate bisa sangat baik untuk skill langka

# Fiverr Gig Optimization

## Struktur Gig Efektif
1. **Title**: [Service] for [Target] — [Benefit]
2. **Description**: Problem → Solution → Results
3. **Packages**: Basic → Standard → Premium
4. **Gallery**: Screenshot, PDF, video
5. **FAQ**: Jawab concern umum

## Optimasi SEO Gig
- Riset keyword di search Fiverr
- Gunakan keyword di title & tags
- Deskripsi dengan keyword natural
- Kategori & subkategori yang tepat

## Response to Buyer Requests
```
Hi! Saya bisa bantu dengan [project]...

Saya punya pengalaman di [skill] dan sudah mengerjakan [X] proyek serupa.

Untuk project ini, saya rekomendasikan paket [Standard] karena...

Saya bisa mulai dalam [X] hari.

Terima kasih!
```

## Tips
- Aktifkan "Response in 1 hour" badge
- Update gig secara berkala
- Gunakan video intro untuk gig utama
- Offering extras untuk upsell

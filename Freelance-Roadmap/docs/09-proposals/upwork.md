# Upwork Proposal Strategy

## Struktur Proposal Upwork
1. **Cover Letter** — 2–3 paragraf
2. **Portfolio** — 2–3 project relevan
3. **Employment history** — Jika relevan
4. **Questions** — Tanya 1–2 pertanyaan cerdas

## Cover Letter Template
```
Hi [Client Name],

I read your project about [problem] and I can help.

I recently completed a similar project: [1-line case study].

My approach:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Timeline: [X] days | Budget: $[Y]

Here's a link to my portfolio: [link]

Let me know if you'd like to discuss further.

Best,
[Name]
```

## Tips
- Kirim di 2 jam pertama setelah job posted
- Rate kompetitif untuk first few projects
- Jangan pakai template kaku — personalisasikan
- Attach file portfolio jika relevan

# LinkedIn Proposal & Outreach

## Connection Request
```
Hi [Name], I follow [Company]'s work in [niche]. Would love to connect!
```

## After Connected
```
Thanks for connecting! I specialize in [service] for [target].

I see [Company] is doing [something]. If you ever need [skill], happy to help.

Keep up the great work!
```

## InMail Template (Premium)
```
Hi [Name],

Quick question: are you handling [problem] in-house or open to external help?

I recently helped [similar company] achieve [result] using [approach].

Here's a case study: [link]

Open to a 15-min chat?

Best,
[Name]
```

## Tips
- Jangan jualan di connection request
- Bangun hubungan dulu sebelum offer
- Share value — artikel, insight, case study
- Gunakan LinkedIn sebagai trust-building, bukan sales channel langsung

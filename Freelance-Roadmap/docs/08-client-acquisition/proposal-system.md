# Proposal System

## Struktur Proposal Efektif
1. **Hook** — Kalimat pertama menarik perhatian
2. **Pemahaman** — Tunjukkan kamu mengerti masalah klien
3. **Solusi** — Pendekatan yang kamu tawarkan
4. **Proof** — Portofolio / case study relevan
5. **CTA** — Ajak diskusi lebih lanjut

## Template Per Platform
Lihat folder `templates/` dan `docs/09-proposals/`.

## Sistem Tracking
| Tool | Fungsi |
|------|--------|
| Spreadsheet | Track semua proposal |
| CRM (HubSpot) | Lead & pipeline management |
| Notion | Knowledge base proposal |

## Metrik Proposal
- **Send rate**: 5–10 proposal/hari
- **Response rate**: Target >50%
- **Interview rate**: Target >20%
- **Conversion rate**: Target >10%

## Iterasi
- A/B test subject line
- A/B test hook
- Track mana yang paling efektif
- Update template tiap bulan

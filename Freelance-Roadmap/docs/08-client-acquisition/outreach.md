# Outreach Strategy

## Cold LinkedIn Outreach
### Prospecting
- Cari decision makers (founder, CEO, CTO, Head of Product)
- Filter: startup early stage, tech company, <200 employees

### Template Message
```
Hi [Name],

I've been following [Company] and noticed [specific observation].

I help [target audience] with [service] to [result]. For example, [brief case study].

Would you be open to a quick chat?

Best,
[Name]
[Portfolio link]
```

## Cold Email Outreach
### Tools
- Apollo.io / Instantly / Lemlist
- Hunter.io untuk email finding

### Best Practices
- Personalisasi, bukan copy-paste
- Value-first, jual hasil bukan jasa
- Follow-up sequence: 3–5 emails
- Track open rate & reply rate

## Do's & Don'ts
✅ Riset prospek sebelum menghubungi
✅ Fokus ke value untuk mereka
✅ Follow-up setelah 3–5 hari
❌ Kirim massal tanpa personalisasi
❌ Langsung jualan di first message
❌ Spam follow-up tiap hari

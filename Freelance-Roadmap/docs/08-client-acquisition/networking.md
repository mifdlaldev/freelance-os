# Networking & Referral

## Why Networking
- **50%+ higher conversion** dibanding cold outreach
- **Better clients** — karena trust sudah ada
- **Free leads** — referral datang sendiri

## Online Networking
- LinkedIn: engage di posting target klien
- Discord: join server niche, bantu jawab pertanyaan
- Twitter/X: follow & interact dengan founder
- Forum: Stack Overflow, Reddit niche

## Offline Networking
- Meetup / tech event lokal
- Workshop / seminar
- Coworking space
- Komunitas freelance Indonesia

## Referral System
1. Kirim email referral request setelah proyek selesai
2. Tawarkan referral fee (10–20%) sebagai insentif
3. Minta testimonial yang bisa dishare
4. Bikin referral program sederhana

## Daily Actions
- [ ] 1-2 LinkedIn engagement (comment meaningful)
- [ ] Jawab pertanyaan di komunitas/forum
- [ ] Kirim 1 "just checking in" ke koneksi lama

# Approved Data Sources

## Purpose

This document defines the approved data sources used throughout the Freelance OS project.

The objective is to ensure that every analysis, recommendation, and strategic decision is based on reliable, transparent, and verifiable information.

---

# Source Priority

All data sources are classified into four confidence levels.

| Level | Description | Decision Weight |
|--------|-------------|----------------:|
| A | Official data and primary sources | 100% |
| B | Trusted secondary sources | 80% |
| C | Community observations | 40% |
| D | Personal opinions or anecdotal evidence | 0% |

Strategic decisions should only be based on Level A and Level B sources.

---

# Level B — Trusted Secondary Sources

Examples:

- McKinsey
- Deloitte
- PwC
- Statista

- Stack Overflow Developer Survey

These sources are suitable when primary data is unavailable.

---

# Level C — Community Sources

Community sources are useful for identifying early signals but should not be treated as proof.

Examples:

- Reddit
- Hacker News
- LinkedIn discussions
- X (Twitter)
- Discord
- Facebook Groups

Community observations require validation before influencing strategic decisions.

---

# Level D — Unsupported Sources

The following should never be used as evidence:

- Personal opinions
- Clickbait articles
- AI-generated content without verification
- Anonymous blog posts
- Unverified YouTube claims

These sources may inspire research questions but cannot support conclusions.

---

# Data Validation Rules

Before using any data:

- Verify the publication date.
- Verify the original source.
- Compare with at least one additional reliable source.
- Record conflicting information when necessary.
- Prefer recent information unless historical context is required.

---

# Citation Policy

Every important claim should be traceable to one or more reliable sources.

Whenever possible:

- cite the original source
- include publication date
- avoid quoting secondary summaries

---

# Review Checklist

Before publishing a research document:

- [ ] Sources are documented
- [ ] Confidence level is appropriate
- [ ] Primary sources are prioritized
- [ ] Data has been cross-checked
- [ ] Conclusions match the evidence

---

# Definition of Done

A research document is considered valid only if every important conclusion can be traced back to approved data sources defined in this document.

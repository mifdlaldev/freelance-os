# Niches

Analisis dan strategi pemilihan niche freelance.

## 🎯 Mengapa Niche Penting

| Generalist | Specialist |
|-----------|------------|
| Rate rendah | Premium pricing |
| Banyak pesaing | Persaingan terbatas |
| Sulit branding | Mudah dikenal |
| Proyek random | Proyek yang sesuai |

## 🔍 Cara Memilih Niche

1. **Skill yang kamu kuasai** — apa yang sudah kamu bisa?
2. **Market demand** — apa yang pasar butuhkan?
3. **Profitability** — apakah niche ini menguntungkan?
4. **Sustainability** — apakah demand jangka panjang?
5. **Personal interest** — apa yang kamu nikmati?

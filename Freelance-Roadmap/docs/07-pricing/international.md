# Pricing — International

## Rate Reference
| Tier | Rate/jam | Rate/project |
|------|----------|-------------|
| Entry | $10–$25 | $100–$500 |
| Mid | $25–$60 | $500–$3,000 |
| Senior | $60–$100 | $3,000–$10,000 |
| Expert | $100–$200+ | $10,000+ |

## Strategi Global
- **Value-based pricing** — Harga berdasarkan nilai yang diberikan, bukan jam
- **Bundle services** — Tingkatkan project value
- **Naikkan rate tiap kuartal**
- **Gunakan escrow** untuk proteksi pembayaran

## Metode Pembayaran
- Wise (recommended)
- PayPal
- Payoneer
- Wire transfer

## Negosiasi
- Jangan turun rate tanpa alasan
- Tawarkan scope reduction instead of discount
- Tahu BATNA (Best Alternative to Negotiated Agreement)

# Hourly Pricing

## Kelebihan
- Pembayaran untuk semua waktu kerja
- Cocok untuk ongoing support / maintenance
- Transparan untuk klien
- Mudah untuk scope yang tidak jelas

## Kekurangan
- Membatasi potensi earning (24 jam/hari)
- Klien fokus ke jam, bukan value
- Perlu tracking tool (Toggl, Clockify)

## Tips
- **Minimum charge**: Minimal 1 jam untuk task kecil
- **Round up**: Bulatkan ke 15/30 menit terdekat
- **Different rates**: Bisa beda rate untuk task berbeda
- **Overtime**: Rate 1.5x untuk urgent request

## Kapan Pakai Hourly
- Maintenance & support
- Scope belum jelas
- Ongoing retainer
- Debugging & troubleshooting

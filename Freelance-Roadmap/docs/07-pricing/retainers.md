# Retainer Pricing

## Kelebihan
- Pendapatan bulanan tetap & predictable
- Tidak perlu hunting klien tiap bulan
- Klien lebih loyal
- Bisa planning finansial lebih baik

## Model Retainer
| Model | Deskripsi | Contoh Harga |
|-------|-----------|-------------|
| Time-based | X jam/bulan | $500/20 jam |
| Task-based | X task/bulan | $750/5 task |
| Value-based | Based on impact | $1,000–$5,000+ |
| Support | On-call + maintenance | $300–$1,000 |

## Cara Menawarkan
1. Setelah proyek selesai — "Saya juga ada paket maintenance"
2. Saat klien butuh ongoing support
3. Sebagai upsell dari proyek fixed-price

## Tips Retainer
- Auto-invoice setiap bulan
- Komunikasi proaktif, jangan nunggu dikontak
- Review retainer tiap 3 bulan — adjust rate jika perlu
- Bikin klien merasa dapat value lebih dari yang mereka bayar

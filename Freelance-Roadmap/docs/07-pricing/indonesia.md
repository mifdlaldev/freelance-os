# Pricing — Indonesia

## Rate Reference
| Tier | Rate/jam | Rate/hari | Rate/bulan |
|------|----------|-----------|------------|
| Entry | Rp 50K–100K | Rp 400K–800K | Rp 5–8JT |
| Mid | Rp 100K–250K | Rp 800K–2JT | Rp 8–15JT |
| Senior | Rp 250K–500K+ | Rp 2JT–4JT | Rp 15–30JT+ |

## Strategi Lokal
- **Mulai kompetitif** untuk portfolio awal
- **Naikkan bertahap** setiap 3–6 bulan
- **Tawarkan paket** untuk meningkatkan project value
- **Payment**: Transfer bank, GoPay, OVO

## Catatan
- Pasar Indonesia lebih price-sensitive
- Value::bangi hasil konkret, bukan jam kerja
- Build reputation untuk justify rate lebih tinggi
